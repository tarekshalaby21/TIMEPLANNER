# BalanceOS 1.1.0 — نظام التوازن والإنجاز

تطبيق ويب تقدمي عربي RTL لإدارة أربعة مسارات: التوازن الشخصي، والتوازن الأسري، وطلب العلم والدعوة، والمشروع الفردي. يعمل محليًا على الجهاز، ويحتفظ بالوظائف الأساسية دون اتصال بعد تحميله أول مرة عبر HTTPS أو localhost.

## ما يميز هذا الإصدار
- 4 نظريات، 16 قسمًا، و278 مهمة/تفريعة جاهزة للتخصيص.
- 48 أيقونة SVG مدمجة ومحلية، مع تعيين أيقونة لكل مهمة وفرعية والبحث عنها.
- بطاقة مهمة غنية بالدافع والعائد والعوائق وخطة التغلب والأثر الواقعي للتأجيل وأول خطوة.
- عادات بثلاثة مستويات: الحد الأدنى، والهدف المعتاد، والتفوق.
- مراجعة متباعدة اختيارية للمواد: 1، 3، 7، 30 يومًا.
- خطة اليوم: مستوى الطاقة، النية، وأهم 3 أولويات.
- صندوق وارد للأفكار، ولوحة أوامر Ctrl+K، واختيار عشوائي لمهمة، ووضع المهمة الواحدة.
- وضع هادئ، مدير وحدات، سمات فاتحة وداكنة وOLED، ووضع استخدام بيد واحدة.
- أصوات تركيز توليدية (بيضاء ووردية)، وWake Lock عند دعم المتصفح.
- خريطة الاستمرارية وساعات النشاط وموجه مراجعة أسبوعية قابل للنسخ.
- سجل الامتنان وتقييم اليوم، وتصدير JSON/CSV/ICS.
- IndexedDB مع نسخة توافق في localStorage وترحيل بيانات الإصدار السابق.

## التشغيل المحلي على Windows
1. فك ضغط الحزمة.
2. شغّل `Start_BalanceOS_Local.bat` إذا كان Python 3 مثبتًا.
3. يفتح المتصفح على `http://127.0.0.1:8765/`، وتظل نافذة الطرفية مفتوحة لتشغيل الخادم.
4. لإيقاف الخادم أغلق نافذة الطرفية.

بديل يدوي:

```bash
python -m http.server 8765
```

ثم افتح `http://localhost:8765/`.

**لا تفتح `index.html` مباشرة من مدير الملفات**؛ تحتاج Service Worker وملفات JSON إلى HTTPS أو localhost.

## التثبيت كتطبيق
- Android: افتح الرابط في Chrome واختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- Desktop: استخدم رمز التثبيت في شريط العنوان إذا ظهر.

## البيانات والخصوصية
- لا يحتاج الإصدار إلى حساب أو خادم خارجي.
- البيانات تحفظ على جهاز المستخدم في IndexedDB، مع نسخة توافق في localStorage.
- لا توجد مزامنة تلقائية بين الأجهزة في هذا الإصدار.
- لا يحتوي على تحليلات خارجية أو مكتبات CDN.
- لا ترفع ملفات النسخ الاحتياطية علنًا؛ فقد تحتوي على تفاصيل شخصية.
- صدّر نسخة JSON دورية واحفظها في مكان آمن.

## النشر
راجع `PUBLISH_GUIDE_AR.md` لنشر المجلد على استضافة HTTPS ثابتة.

## الاختبارات والنطاق
- شغّل `node tests/logic-smoke.cjs` لاختبار منطق القوالب والترحيل والعادات والمراجعة المتباعدة وتصدير التقويم.
- راجع `TEST_REPORT_AR.md` لنتائج الاختبار وحدوده.
- راجع `IMPLEMENTATION_SCOPE_AR.md` لمعرفة الميزات المنفذة وما تم تأجيله إلى الإصدارات القادمة.

## تكامل Time Planner
يمكن تصدير إعدادات النظريات من التطبيق بصيغة JSON لاستخدامها في Time Planner Balance Builder المحلي. بناء قاعدة SQLite مباشرة يحتاج إلى Companion محلي منفصل، وهو غير مضمن في النسخة العامة.
