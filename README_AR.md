# BalanceOS — الإصدار العام PWA

تطبيق عربي لإدارة منظومات التوازن الشخصي والأسري والعلمي/الدعوي والمشروع الفردي. يشمل المهام والعادات والأهداف والسجل اليومي ومؤقت التركيز والتحليلات والتحفيز.

## النشر

هذه حزمة الواجهة العامة فقط. ارفع محتوياتها إلى استضافة ملفات ثابتة تعمل عبر HTTPS مثل GitHub Pages أو Cloudflare Pages أو Netlify أو Vercel، مع إبقاء `index.html` في جذر النشر والمحافظة على مجلدَي `assets` و`data`.

بعد النشر، افتح الموقع على Android ثم اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق» من قائمة المتصفح.

## ما يقدمه التطبيق

- أربع نظريات جاهزة ومرنة: الشخصية، الأسرية، العلمية/الدعوية، والمشروع الفردي.
- 16 قسمًا و278 مهمة وتفريعة ضمن القوالب الأساسية.
- إنشاء نظريات وأقسام ومهام وعادات وأهداف إضافية.
- جدول يومي وأسبوعي، متابعة الإنجاز، وتسجيل يومي.
- ربط المهام بالأهداف، ومؤقت تركيز، وتحليلات 7/30/90 يومًا.
- نقاط خبرة ومستويات وعملات وشارات وتحديات أسبوعية ومكافآت يحددها المستخدم.
- أيام راحة ووضع إجازة يجمّد سلسلة الاستمرارية، دون خصم نقاط عند تفويت يوم.
- نسخ احتياطي واستعادة JSON وتصدير CSV.
- دعم PWA والتخزين المحلي والعمل دون اتصال بعد تحميل التطبيق وملفاته بنجاح.

## الخصوصية وحدود الإصدار

- تحفظ البيانات محليًا في المتصفح على الجهاز/ملف المتصفح الحالي.
- لا توجد حسابات أو مزامنة سحابية بين الأجهزة في هذا الإصدار.
- صدّر نسخة JSON احتياطية دوريًا.
- عند النشر العام، لا ترفع أي قاعدة بيانات شخصية أو نسخة Time Planner أصلية.

## ملف النشر

راجع `PUBLISH_GUIDE_AR.md` لمعرفة خطوات النشر والتثبيت وحدود هذا الإصدار.
